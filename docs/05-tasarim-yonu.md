# Tasarım Yönü (Claude Design Brief'i)

## Stil
Soğuk, sofistike, editoryal, iddialı tipografi — "dergi kapağı" hissi

## Anti-referans
Klasik "berber dükkanı" şablonları (tuğla doku, turuncu/amber, kalın gölgeli
fontlar) — KAÇINILACAK

## Palet
Koyu/soğuk zemin (lacivert/antrasit/gri-mavi) + 1 net vurgu rengi, saf
siyah/beyaz yerine kırık tonlar

## Tipografi
Sadece 2 font ailesi, büyük/kalın başlıklar

## Tasarlanan 3 Ekran
1. Ana sayfa
2. Randevu formu (4 adım)
3. Admin dashboard

## Durum
Mockup Claude Design'da tamamlandı ve onaylandı. Claude Code'da gerçek
geliştirmeye bu yön doğrultusunda geçiliyor.
